# qa-api-serverest

Automação de testes de API para a [ServeRest](https://serverest.dev/) com **Playwright Test** e **TypeScript**.

> Projeto em construção — Case Técnico de QA Automation (API).

## Pré-requisitos

- Node.js 18+
- npm

## Setup rápido

```bash
npm ci
npx playwright install --with-deps
```

## Executar testes

```bash
npm run testar
```

Documentação completa em [`docs/PLANEJAMENTO.md`](docs/PLANEJAMENTO.md).
